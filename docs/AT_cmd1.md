# GMR MES ATC 通话与短信 AT 命令汇总

> **数据来源：** 《GMR MES Function Structure Design ATC》
> **整理日期：** 2026-06-01

## 一、通话相关 AT 命令 (CS 域)

| AT 命令 | 功能说明 | 命令格式示例 | 主要参数说明 |
| :--- | :--- | :--- | :--- |
| `ATA` | 应答来电 | `ATA` | 无参数 |
| `ATD` | 发起呼叫 (语音/视频) | `ATD10086;` (语音) <br> `ATD10086` (视频) | `<n>`: 号码; `;` : 语音呼叫修饰符 |
| `AT+CHUP` | 挂断/拒绝呼叫 | `AT+CHUP` | 无参数 |
| `AT+CLIP` | 主叫号码显示 | `AT+CLIP=1` | `<n>`: 0-禁止, 1-使能 |
| `AT+CLIR` | 主叫号码限制 | `AT+CLIR=1` | `<n>`: 0-使用订阅, 1-限制, 2-解除限制 |
| `AT+COLP` | 连接号码显示 | `AT+COLP=1` | `<n>`: 0-禁止, 1-使能 |
| `AT+CCWA` | 呼叫等待 | `AT+CCWA=1,1` | `<n>`: 0-禁止, 1-使能; `<mode>`: 0-去激活, 1-激活, 2-查询 |
| `AT+CHLD` | 呼叫保持/多方通话 | `AT+CHLD=2` (保持当前通话, 接听等待) | `<n>`: 0-释放, 1-释放并接听, 2-保持并接听, 3-多方通话 |
| `AT+CLCC` | 查询当前呼叫列表 | `AT+CLCC` | 无参数 |
| `AT+CMUT` | 静音控制 | `AT+CMUT=1` | `<n>`: 0-关闭静音, 1-开启静音 |
| `AT+VTS` | 发送 DTMF 音 | `AT+VTS=1` | `<dtmf>`: 0-9, #, *, A-D |
| `AT+CEER` | 查询上次呼叫失败原因 | `AT+CEER` | 无参数 |
| `ATS0` | 设置自动接听 (秒) | `ATS0=10` | `<n>`: 等待秒数, 0-关闭 |
| `AT+CSTA` | 选择地址类型 | `AT+CSTA=145` | `<type>`: 145-国际号码, 129-国内号码 |
| `AT+CRC` | 扩展来电指示 | `AT+CRC=1` | `<mode>`: 0-标准, 1-扩展格式 (+CRING) |
| `AT+CMOD` | 设置呼叫模式 (仅支持单模式) | `AT+CMOD=0` | `<mode>`: 0-单模式 |
| `AT+CBST` | 选择承载服务类型 | `AT+CBST=0` | `<speed>`: 速率; `<name>`: 承载方式; `<ce>`: 连接方式 |
| `AT^DSCI` | 呼叫状态主动上报开关 | `AT^DSCI=1` | `<n>`: 0-禁止上报, 1-使能上报 |
| `AT^HPAS` | 开启/关闭高穿透振铃 | `AT^HPAS=1` | 0-关闭, 1-开启 |
| `AT^ECC` | 设置紧急呼叫号码 | `AT^ECC=110,119,120` | `<x>`: 紧急呼叫号码 |
| `^ORIG` | (主动上报) 呼叫发起指示 | `^ORIG: 1,0` | `<call_x>`: 呼叫ID; `<call_type>`: 0-语音, 9-紧急 |
| `^CONF` | (主动上报) 网络连通指示 | `^CONF: 1,0` | `<call_x>`: 呼叫ID; `<call_type>`: 呼叫类型 |
| `^CONN` | (主动上报) 呼叫接通指示 | `^CONN: 1,0` | `<call_x>`: 呼叫ID; `<call_type>`: 呼叫类型 |
| `^CEND` | (主动上报) 通话结束指示 | `^CEND: 1,,101,17,0` | `<call_x>`: 呼叫ID; `<end_status>`: 结束原因; `<cc_cause>`: 网络原因码 |
| `^ALERT` | (主动上报) 收到 Alert 消息 | `^ALERT` | 无参数 |

## 二、短信相关 AT 命令

| AT 命令 | 功能说明 | 命令格式示例 | 主要参数说明 |
| :--- | :--- | :--- | :--- |
| `+CMGF` | 设置短信格式 (PDU/Text) | `AT+CMGF=0` | `<mode>`: 0-PDU模式, 1-Text模式 |
| `+CMGS` | 发送短信 (PDU模式) | `AT+CMGS=26` | `<length>`: PDU长度; `<pdu>`: 协议数据单元 |
| `+CMGL` | 短信列表 | `AT+CMGL=0` | `<stat>`: 0-未读, 1-已读, 2-未发, 3-已发, 4-全部 |
| `+CMGR` | 读取指定短信 | `AT+CMGR=1` | `<index>`: 短信位置序号 |
| `+CMGD` | 删除短信 | `AT+CMGD=1` | `<index>`: 短信位置序号; `<delflag>`: 批量删除标志 |
| `+CMGW` | 存储短信到SIM卡 | `AT+CMGW=8` | `<length>`: PDU长度; `<stat>`: 存储状态 |
| `+CMGC` | 发送短信命令 | 格式同`+CMGS` | 用于发送命令，而非普通短信 |
| `+CNMA` | 新短信确认 | `AT+CNMA=2,8` | `<n>`: 1-成功确认, 2-失败确认; `<ackpdu>`: 确认PDU |
| `+CMTI` | (主动上报) 新短信到达 | `+CMTI: "SM",2` | `<mem>`: 存储介质; `<index>`: 位置序号 |
| `+CMT` | (主动上报) 新短信直接上报 | `+CMT: 8` | `<length>`: PDU长度; `<pdu>`: 协议数据单元 |
| `+CDSI` | (主动上报) 状态报告到达 | `+CDSI: "SM",356` | `<mem>`: 存储介质; `<index>`: 位置序号 |
| `+CDS` | (主动上报) 状态报告直接上报 | `+CDS: 8` | `<length>`: PDU长度; `<pdu>`: 协议数据单元 |
| `+CNMI` | 新短信通知设置 | `AT+CNMI=2,1,0,1,0` | `<mode>`: 缓存/直发; `<mt>`: 新短信规则; `<ds>`: 状态报告规则 |
| `+CPMS` | 选择短信存储位置 | `AT+CPMS="SM"` | `<mem1>`: 读取/删除; `<mem2>`: 写入/发送; `<mem3>`: 存储 |
| `+CSCA` | 设置/查询短信中心号码 | `AT+CSCA="+8613800100500"` | `<sca>`: 短信中心号码; `<tosca>`: 号码类型 |
| `+CSMS` | 选择短信服务类型 | `AT+CSMS=0` | `<service>`: 0/1 (是否需确认回复) |
| `+CGSMS` | 选择短信承载域 (CS/PS) | `AT+CGSMS=1` | `<service>`: 0-PS, 1-CS, 2-PS优先, 3-CS优先 |
| `+CSCB` | 选择小区广播消息类型 | `AT+CSCB=0` | `<mode>`: 0-接受, 1-不接受; `<mids>`: 消息ID组 |
| `+CMMS` | 设置短信连发模式 | `AT+CMMS=1` | `<n>`: 0-单发, 1-连发, 2-保持连发 |
| `+CSAS` | 保存短信设置到SIM卡 | `AT+CSAS` | `<profile>`: 存储位置 (默认0) |
| `^CMGS` | (扩展) 短信连发命令 | `AT^CMGS=1,26` | `<n>`: 0-非连发, 1-连发; `<length>`: PDU长度 |
| `^SWCB` | 开启/关闭小区广播 | `AT^SWCB=1,1` | `<mode>`: 0-关闭, 1-开启; `<DRX>`: 0-关闭, 1-开启 |
| `^CMFL` | 通知ATC短信存储空间状态 | `AT^CMFL=1` | `<n>`: 0-可存储, 1-无空间 |

**备注：**
- 以上命令均来源于《GMR MES Function Structure Design ATC》，`^` 开头的命令多为厂商自定义的扩展命令或主动上报的结果码。
- 文档中原始标注为“暂不支持”的命令，此表中已剔除。
