# da228EC 三轴加速度计开发指南 (Rev 0.1)

> **芯片型号**: MiraMEMS da228EC
> **文档版本**: Rev 0.1 (2021年11月)
> **核心特性**: 低功耗、高性能、3轴、数字输出 (I2C)

## 1. 芯片概述

da228EC是一款基于微机械加工技术（MEMS）的电容式三轴线性加速度计。它通过I2C接口与主机通信，具备低功耗、高性能的特点。

- **封装**: 2x2x1.1 mm LGA-12
- **工作温度**: -40°C 至 +85°C
- **分辨率**: 12位
- **接口**: I2C (最大 400 kHz)

## 4. 核心功能与配置

### 4.1. 工作模式 (MODE_BW, 0x11)

- **`pwr_mode[1:0]`**:
  - `00`: 正常模式 (Normal)
  - `01`: 低功耗模式 (Low Power)
  - `1x`: 挂起模式 (Suspend)

### 4.2. 量程设置 (RANGE, 0x0F)

- **`fs[1:0]`**:
  - `00`: ±2g
  - `01`: ±4g
  - `10`: ±8g

- **灵敏度 (So)**: (与量程对应)
  - ±2g: 1024 LSB/g
  - ±4g: 512 LSB/g
  - ±8g: 256 LSB/g

### 4.3. 数据速率 (ODR_AXIS, 0x10)

- **`ODR[3:0]`**: 可从 1Hz 到 1000Hz 选择。
  - `0000`: 1Hz
  - `0111`: 125Hz
  - `1001`: 500Hz
  - `1010-1111`: 1000Hz (默认复位值为0FH)

### 4.4. 加速度数据 (0x02 - 0x07)

- **格式**: 12位有符号二进制补码，左对齐。
- **组合**: `data = (ACC_X_MSB << 4) | (ACC_X_LSB >> 4)`
  - **MSB**: 存储高8位 `data[11:4]`。
  - **LSB**: 存储低4位 `data[3:0]` (高4位未使用)。

## 5. 中断系统

### 5.1. 中断类型

1.  **新数据中断 (New Data Interrupt)**: 每次新的加速度数据准备就绪时触发。
2.  **活动检测中断 (Active Detection Interrupt)**: 检测到运动状态变化时触发。

### 5.2. 中断配置流程

1.  **使能中断**: 配置 `INT_SET1` (0x16) 和 `INT_SET2` (0x17) 使能所需中断类型。
    - `INT_SET1`: `active_int_en_x/y/z` (使能特定轴的活动检测)
    - `INT_SET2`: `new_data_int_en` (使能新数据中断)
2.  **映射中断**: 配置 `INT_MAP1` (0x19) 和 `INT_MAP2` (0x1A) 将中断映射到物理引脚。
    - `INT_MAP1`: `INT_active` (映射活动中断到 INT 引脚)
    - `INT_MAP2`: `INT_new_data` (映射新数据中断到 INT 引脚)
3.  **配置电气特性**: 配置 `INT_CONFIG` (0x20) 设置引脚输出类型和有效电平。
    - `INT_od`: 0=推挽, 1=开漏
    - `INT_lvl`: 0=低有效, 1=高有效
4.  **配置锁存模式**: 配置 `INT_LATCH` (0x21) 设置中断行为。
    - `0000`/`1000`: 非锁存 (Non-latched)
    - `0111`/`1111`: 永久锁存 (Latched)
    - 其他值: 临时锁存特定时长 (如 250ms, 1s)。

### 5.3. 活动检测 (Active Detection)

- **原理**: 检测连续加速度样本之间的斜率变化。
- **阈值配置 (`ACTIVE_THS`, 0x28)**: `阈值的加速度值 = active_th * K`
  - K 取决于量程: ±2g 时 K=3.91mg, ±4g 时 K=7.81mg, ±8g 时 K=15.625mg。
- **持续时间配置 (`ACTIVE_DUR`, 0x27)**: `持续时间 = (active_dur + 1) ms`。斜率必须连续超过阈值这段时间才触发中断。
- **状态寄存器 (`ACTIVE_STATUS`, 0x0B)**: 读取哪个轴 (`active_first_x/y/z`) 和方向 (`active_sign`) 首先触发了中断。

## 6. 初始化建议流程

```text
1.  [验证] 读取 CHIPID (0x01) → 验证返回值是否为 0x13
2.  [配置] RANGE (0x0F) → 设置量程 (±2g, ±4g, ±8g)
3.  [配置] ODR_AXIS (0x10) → 设置输出数据速率
4.  [配置] MODE_BW (0x11) → 写入 0x9E 进入正常模式并设置带宽
5.  [中断] INT_SET1 / INT_SET2 → 使能所需中断
6.  [中断] INT_MAP1 / INT_MAP2 → 将中断映射到 INT 引脚
7.  [中断] INT_LATCH → 设置中断锁存模式
8.  [中断] INT_CONFIG → 设置中断引脚电气特性
9.  [可选] ACTIVE_THS / ACTIVE_DUR → 配置活动检测阈值和时长
10. [循环] 读取加速度数据
