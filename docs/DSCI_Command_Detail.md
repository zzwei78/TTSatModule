# AT^DSCI — 呼叫状态指示命令 (详情)

> **文档来源：** 《GMR MES Function Structure Design ATC》 (V1.34)
> **数据类型：** AT 命令 (SET / READ / TEST) 及 URC 主动上报

---

## 1. 功能描述

该命令用于设置**是否开启**呼叫状态发生改变时的**主动上报**功能。

当开启 (`<n>=1`) 且任一呼叫状态发生变化时，调制解调器 (MS) 会自动向应用端 (TE) 上报一条包含详细呼叫状态信息的 URC 数据。

---

## 2. 命令格式

| 命令形式 | 格式 | 可能的响应 |
| :--- | :--- | :--- |
| **SET** | `AT^DSCI=<n>` | `OK` |
| **READ** | `AT^DSCI?` | `<CR><LF>^DSCI: <n><CR><LF><CR><LF>OK<CR><LF>` |
| **TEST** | `AT^DSCI=?` | `<CR><LF>OK<CR><LF>` |

### 参数 `<n>`

| 值 | 说明 |
| :--- | :--- |
| `0` | **关闭**呼叫状态主动上报（默认值） |
| `1` | **开启**呼叫状态主动上报 |

---

## 3. 主动上报格式

当 `<n> = 1` 时，状态改变触发上报，格式如下：

^DSCI: <id>,<dir>,<stat>,<type>,<mpty>,<number>,<num_type>[,<bs_type>][,<cause>]

---

## 4. 上报字段详解

| 字段 | 类型 | 取值范围 | 说明 |
| :--- | :--- | :--- | :--- |
| `<id>` | 整数 | 1 – 7 | **呼叫标识**，用于 `AT+CHLD` 命令引用 |
| `<dir>` | 整数 | 0 – 1 | **呼叫方向** <br> `0`：用户发起的呼叫 (MO) <br> `1`：用户终结的呼叫 (MT) |
| `<stat>` | 整数 | 0 – 6 | **呼叫状态** <br> `0`：活动中 (Active) <br> `1`：保留中 (Hold) <br> `2`：拨号中 (MO) <br> `3`：振铃中 (MO) <br> `4`：来电建立中 (MT) <br> `5`：等待中 (Waiting) <br> **`6`：呼叫结束** |
| `<type>` | 整数 | 0 – 1 | **呼叫类型** <br> `0`：语音业务 <br> `1`：数据业务 |
| `<mpty>` | 整数 | 0 – 1 | **是否在多方通话** <br> `0`：不在 <br> `1`：在多方通话中 |
| `<number>` | 字符串 | – | **呼叫地址号码**，格式由 `<num_type>` 指定 |
| `<num_type>` | 整数 | 129 / 145 等 | **地址类型**，参考 TS 24.008：<br> `129`：国内号码 <br> `145`：国际号码 |
| `<bs_type>` | 整数 | 0 – 3 | **仅当 `<type>` ≠ 0（非语音）时有效**，指明数据业务具体类型： <br> `0`：ASYNC 异步透明 <br> `1`：SYNC 同步透明 <br> `2`：REL ASYNC 异步非透明 <br> `3`：REL SYNC 同步非透明 |
| `<cause>` | 整数 | – | **呼叫挂断原因值**，参考 3GPP TS 24.008 第 10.5.4.11 节，**仅在 `<stat>=6`（呼叫结束）时出现** |

---

## 5. 命令实例

### 开启上报

AT^DSCI=1
OK


### 查询当前设置
AT^DSCI?
^DSCI: 1
OK


### 测试命令支持性
AT^DSCI=?
OK


### 主动上报实例
**实例 1：语音呼叫正常结束（MO）**
^DSCI: 1,0,6,0,0,"10086",129

> 解释：呼叫ID=1，MO方向，状态=呼叫结束(6)，语音业务(0)，非多方通话(0)，号码"10086"，国内号码类型(129)。

**实例 2：有来电建立（MT）**
^DSCI: 2,1,4,0,0,"13800138000",145

> 解释：呼叫ID=2，MT方向，状态=来电建立中(4)，语音业务(0)，非多方通话(0)，号码"13800138000"，国际号码类型(145)。

---

## 6. 注意事项

1. **命令响应**：SET 命令收到后立即返回 `OK`，并开启/关闭功能，不会等待状态改变。
2. **READ 返回值**：仅返回 `<n>` 的设定值（`0` 或 `1`）。
3. **TEST 返回值**：始终返回 `OK`，表示该命令被支持。
4. **触发时机**：仅在呼叫状态发生改变时上报，包括发起、接通、保持、等待、结束等任一动作。
5. **多通话场景**：若存在多个呼叫（如多方通话），每个呼叫的独立状态变化都会触发各自的 `^DSCI` 上报。
6. **`<cause>` 字段**：仅在 `stat=6`（呼叫结束）时才可能携带，用于指示挂断原因。
