MMC5603NJ 开发手册
1. 芯片概述
MMC5603NJ 是 MEMSIC 公司的一款单芯片三轴 AMR（各向异性磁阻）磁传感器，具有以下特性 ：

测量范围：±30 Gauss
分辨率：最高 20 位（0.0625mG/LSB）
总 RMS 噪声：低至 2mG
航向精度：±1°
接口：I²C（Fast Mode，≤400KHz）和 I3C
电源：1.62V ~ 3.6V 单电源，1.2V 逻辑 IO
封装：超小型 WLP 0.8×0.8×0.4mm
功耗：待机电流低至 1μA
片上特性：SET/RESET 功能消除温度漂移、片上灵敏度补偿、片上温度传感器、自检信号

2. 引脚定义（WLP 封装）

3. I²C 接口特性

I²C 设备地址：7 位地址 [0110000]（0x30），最低 3 位由工厂预编程，最多支持 8 种不同地址 
最大时钟频率：400KHz（Fast Mode）
上拉电阻选择：短总线（<10cm）用 2.7KΩ，更短总线（<5cm）用 10KΩ

5. 寄存器详细说明
5.1 磁场数据寄存器（Xout0/1/2, Yout0/1/2, Zout0/1/2）— 地址 00H~08H
每个轴的数据由 3 个寄存器组成，共 20 位数据：
表格寄存器地址位描述Xout000HXout[19:12]Xout101HXout[11:4]Xout206HXout[3:0]（高4位有效，低4位为0）
Y、Z 轴同理。模式：只读 
20位模式数据组合：Xout = (Xout0 << 12) | (Xout1 << 4) | (Xout2 >> 4)
灵敏度：20位模式下 16384 counts/G，零场输出约 524288 counts 
5.2 温度寄存器（Tout）— 地址 09H

格式：无符号整数
范围：-75°C ~ 125°C
分辨率：约 0.8°C/LSB
0x00 = -75°C
模式：只读 

5.3 状态寄存器（Status1）— 地址 18H

模式：只读

6. 操作示例
6.1 单次磁场测量流程
1. 主机发送 START + 设备地址 0x30（写）
2. 发送寄存器地址 0x1B（Internal Control 0）
3. 写入值 0x21（Take_meas_M=1, Auto_SR_en=1）→ 启动测量
4. 发送 STOP
5. 读取 Status1 (0x18)，等待 Meas_m_done 位（bit 6）置1
6. 从 Xout0~Zout2 读取数据（地址 0x00 开始，连续读9字节）

6.2 SET 操作流程
1. 写入 0x1B 寄存器为 0x08（Do Set=1）→ 执行 SET 操作（375ns）
2. 操作完成后该位自清除

6.3 RESET 操作流程
1. 写入 0x1B 寄存器为 0x10（Do Reset=1）→ 执行 RESET 操作（375ns）
2. 操作完成后该位自清除

6.4 连续模式配置流程
1. 写入 ODR 寄存器 (0x1A) 为非零值（如 75）
2. 写入 0x1B 寄存器，Cmm_freq_en=1（bit 7）
3. 等待内部计算完成
4. 写入 0x1D 寄存器，Cmm_en=1（bit 4）→ 启动连续模式

6.5 自检流程
1. 读取 ST_X/ST_Y/ST_Z 寄存器（27H~29H）获取自检信号值
2. 计算阈值为读取值的80%，写入 ST_X_TH/ST_Y_TH/ST_Z_TH（1EH~20H）
3. 写入 0x1B 寄存器为 0x41（TM_M=1, Auto_st_en=1）→ 启动自检
4. 读取 Status1 (0x18) 的 Sat_sensor 位
5. Sat_sensor=0 → 自检通过
