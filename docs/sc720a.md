# SC7A20H 三轴加速度计开发指南

> **芯片型号**: 士兰微电子 SC7A20H
> **核心特性**: 高精度数字三轴加速度计，内置丰富功能，超低功耗，小体积
> **接口**: I²C / SPI
> **典型应用**: 运动检测、自由落体、6D方向检测、单击/双击检测、睡眠唤醒

## 1. 芯片概述

SC7A20H 是一款高精度数字三轴加速度传感器芯片，内置功能丰富，功耗更低，体积更小，测量更精确。芯片通过 I²C/SPI 接口与 MCU 通信，加速度测量数据以中断方式或查询方式获取。

### 关键特性

- **供电电压**: 1.71V 至 3.6V
- **1.8V 兼容数字 IO 口**
- **量程**: ±2g / ±4g / ±8g / ±16g（用户可选）
- **分辨率**: 12 位
- **接口**: I²C（快速模式400kHz） / SPI
- **工作温度**: -40°C 至 +85°C
- **低功耗电流**: 低至 2µA @1.8V @1.56Hz
- **掉电电流**: 0.5 µA
- **中断**: INT1 和 INT2 两个可编程中断引脚

### 内置功能

- **6D/4D 方向检测**: 检测设备所处的姿态
- **自由落体检测**: 检测自由落体状态
- **单击/双击检测**: 检测点击动作
- **睡眠/唤醒检测**: 实现低功耗运动检测
- **自测试功能**: 无需转台即可检测系统功能
- **内嵌 FIFO**: 支持数据缓存

### 应用领域

- 移动设备用户界面（屏幕旋转、计步）
- 手势识别
- 自由落体检测（硬盘保护）
- 单击/双击检测（智能设备交互）
- 姿态检测

## 3. 通信接口

### 3.1. I²C 接口

#### 3.1.1. I²C 设备地址

SC7A20H 的 I²C 从设备地址为 **001100xb**（具体地址可根据用户需求配置）。

| 方向 | 7位地址 | R/W | 完整字节 |
|:---:|:-------:|:---:|:--------:|
| 写 | 001100x | 0 | 0x30 或 0x32（取决于配置）|
| 读 | 001100x | 1 | 0x31 或 0x33（取决于配置）|

#### 3.1.2. I²C 协议

1. **START** 条件：SCL 为高时，SDA 从高变低
2. 发送 **7位从设备地址 + R/W位**
3. 从设备返回 **ACK**
4. 发送 **8位子地址**（寄存器地址）：
   - 低7位表示实际寄存器地址
   - 最高位表示地址自增（1=自增，支持多字节读写）
5. 读写操作：
   - **写操作**：直接写入数据
   - **读操作**：发送“重复 START” + 设备地址（读模式）

### 3.2. SPI 接口

SC7A20H 支持 SPI 接口（4线制和3线制）。

#### 3.2.1. SPI 协议格式

| Bit | 名称 | 描述 |
|:---:|:----:|:-----|
| Bit0 | RW | 0=写，1=读 |
| Bit1 | MS | 0=地址不自增，1=地址自增 |
| Bit2-7 | AD[5:0] | 寄存器地址（AD6在0EH寄存器中控制）|
| Bit8-15 | DI/DO | 数据（写：输入数据，读：输出数据）|

#### 3.2.2. SPI 时序特点

- 单字节读写以 **16个时钟**完成
- 多字节以8的倍数加时钟
- CS 在传输开始前变低，结束后变高
- SPC 下降沿驱动数据，上升沿读取数据

### 5.2. 数据转换示例

数据为 12 位有符号数，数据恢复和单位转换示例：

```c
// 读取 X 轴原始数据
unsigned char X_H = read_reg(0x29);  // OUT_X_H
unsigned char X_L = read_reg(0x28);  // OUT_X_L

// 转换为有符号16位整数
signed short int raw_x = (signed short int)((X_H << 8) | X_L);

// 根据量程转换为g值
float acc_x_g;
switch (fs_range) {  // fs_range 由 RANGE 寄存器决定
    case 0: // ±2g
        acc_x_g = (float)raw_x / 1024.0f;  // 1 mg/digit
        break;
    case 1: // ±4g
        acc_x_g = (float)raw_x / 512.0f;   // 2 mg/digit
        break;
    case 2: // ±8g
        acc_x_g = (float)raw_x / 256.0f;   // 4 mg/digit
        break;
    case 3: // ±16g
        acc_x_g = (float)raw_x / 128.0f;   // 8 mg/digit
        break;
}

7.2. 数据读取示例

#include <stdint.h>
#include <math.h>

// 读取三轴加速度数据
void read_acceleration(float *x, float *y, float *z) {
    uint8_t x_l = read_reg(0x28);  // OUT_X_L
    uint8_t x_h = read_reg(0x29);  // OUT_X_H
    uint8_t y_l = read_reg(0x2A);  // OUT_Y_L
    uint8_t y_h = read_reg(0x2B);  // OUT_Y_H
    uint8_t z_l = read_reg(0x2C);  // OUT_Z_L
    uint8_t z_h = read_reg(0x2D);  // OUT_Z_H

    // 转换为有符号16位值
    int16_t raw_x = (int16_t)((x_h << 8) | x_l);
    int16_t raw_y = (int16_t)((y_h << 8) | y_l);
    int16_t raw_z = (int16_t)((z_h << 8) | z_l);

    // 假设量程为 ±2g，灵敏度 1 mg/digit (1024 counts/g)
    *x = (float)raw_x / 1024.0f;
    *y = (float)raw_y / 1024.0f;
    *z = (float)raw_z / 1024.0f;
}

## 2. 寄存器详解

### 2.1. SPI_CTRL (0x0E) — SPI控制寄存器

保留寄存器，用于SPI接口的配置。

### 2.2. WHO_AM_I (0x0F) — 设备ID寄存器

| 属性 | 值 |
|:---:|:----:|
| **类型** | 只读 (r) |
| **默认值** | 0x11 |

- **功能**: 用于验证芯片通信是否正常。
- **读取方法**: `uint8_t id = read_reg(0x0F);`
- **验证**: 如果 `id == 0x11`，则通信正常。

### 2.3. CTRL_REG0 (0x1F) — 控制寄存器0

此寄存器包含采样率（ODR）高四位和过采样率（OSR）配置。
