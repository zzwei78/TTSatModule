# 1. da228EC 三轴加速度计

## 1.1 芯片概述

**MiraMEMS da228EC** 是一款低功耗、高性能的电容式三轴线性加速度计，采用微机械加工技术（MEMS）制造，通过 I2C 接口与主机通信。

### 关键特性
- **供电电压**: 1.62V 至 3.6V
- **封装**: 2x2x1.1 mm LGA-12
- **量程**: ±2g / ±4g / ±8g（用户可选）
- **分辨率**: 12 位
- **接口**: I2C（最大 400 kHz）
- **工作温度**: -40°C 至 +85°C
- **功耗**: 正常模式 180 µA，低功耗模式 40 µA，挂起模式 0.7 µA
- **中断**: 1 个可编程中断发生器，支持新数据中断和活动检测中断
- **出厂校准**: 灵敏度和零偏已校准，上电即用

### 应用领域
- 移动设备用户界面（屏幕旋转、计步）
- 手势识别
- 电源管理（静止检测）
- 振动监测
- 姿态/角度检测

## 1.5 核心寄存器详解

### 1.5.1 CONFIG (0x00)

| Bit | 名称 | 描述 |
|:---:|:----:|:-----|
| 5 或 2 | Soft Reset | 写入 1 触发软复位 |

### 1.5.2 CHIPID (0x01) - 只读

- **默认值**: 0x13（用于验证芯片连接）

### 1.5.3 加速度数据寄存器 (0x02 - 0x07)

- **格式**: 12 位有符号二进制补码，左对齐
- **组合**: `data = (MSB << 4) | (LSB >> 4)`
  - MSB: bits[7:0] = data[11:4]
  - LSB: bits[3:0] = data[3:0] (高4位未使用)

### 1.5.4 RANGE (0x0F)

| fs[1:0] | 量程 | 灵敏度 |
|:-------:|:---:|:------:|
| 00 | ±2g | 1024 LSB/g |

| 10 | ±8g | 256 LSB/g |

## 1.6 中断系统

### 1.6.1 中断类型

1. **新数据中断**: 每次新加速度数据就绪时触发
2. **活动检测中断**: 检测到运动状态变化时触发

### 1.6.2 中断配置流程

1. **使能中断**: `INT_SET1 (0x16)` + `INT_SET2 (0x17)`
   - `active_int_en_x/y/z`: 使能各轴活动检测
   - `new_data_int_en`: 使能新数据中断
2. **映射中断**: `INT_MAP1 (0x19)` + `INT_MAP2 (0x1A)`
   - `INT_active`: 映射活动中断到 INT 引脚
   - `INT_new_data`: 映射新数据中断到 INT 引脚
3. **配置电气特性**: `INT_CONFIG (0x20)`
   - `INT_od`: 0=推挽, 1=开漏
   - `INT_lvl`: 0=低有效, 1=高有效
4. **配置锁存模式**: `INT_LATCH (0x21)`

### 1.6.3 中断锁存模式

| latch_INT[3:0] | 模式 |
|:--------------:|:----:|
| 0000 / 1000 | 非锁存 |
| 0001 | 临时锁存 250ms |
| 0010 | 临时锁存 500ms |
| 0011 | 临时锁存 1s |
| 0100 | 临时锁存 2s |
| 0101 | 临时锁存 4s |
| 0110 | 临时锁存 8s |
| 0111 / 1111 | 永久锁存 |

## 1.7 初始化与数据读取

### 1.7.1 初始化流程

```text
1. [验证] 读取 CHIPID (0x01) → 验证为 0x13
2. [配置] RANGE (0x0F) → 设置量程（角度测量推荐 ±2g: 0x00）
3. [配置] ODR_AXIS (0x10) → 设置采样率
4. [配置] MODE_BW (0x11) → 写入 0x1E 进入正常模式
5. [可选] 配置中断相关寄存器


1.7.2 数据读取示例
// 配置

write_reg(0x10, 0x02);   // ODR = 3.9Hz
write_reg(0x11, 0x1E);   // MODE_BW = 正常模式

// 读取 (轮询新数据标志)
while (1) {
    uint8_t flag = read_reg(0x0A);  // NEWDATA_FLAG
    if (flag & 0x01) {
        // 读取 X 轴

        uint8_t x_msb = read_reg(0x03);
        int16_t raw_x = (x_msb << 4) | (x_lsb >> 4);
        if (raw_x & 0x0800) raw_x |= 0xF000;  // 符号扩展
        float acc_x_g = (float)raw_x / 1024.0f;  // ±2g 灵敏度

        // 类似读取 Y, Z 轴
    }
}

### 2.6. 输出数据组合方式

三轴输出均为 **无符号格式**，根据不同的工作模式，有效数据位不同：

| 模式 | 使用的有效位 | 组合方式 |
|:---:|:----------:|:--------:|
| 16 位操作模式 | Xout[19:4] | 仅使用 Xout0 + Xout1 |
| 18 位操作模式 | Xout[19:2] | Xout0 + Xout1 + Xout2[3:2] |
| 20 位操作模式 | Xout[19:0] | Xout0 + Xout1 + Xout2 |

**20 位模式数据恢复示例：**
```c
uint32_t raw_x = ((uint32_t)xout0 << 12) |  // Xout[19:12]
                 ((uint32_t)xout1 << 4)  |  // Xout[11:4]
                 (xout2 & 0x0F);           // Xout[3:0]

16 位模式数据恢复示例：
