# 传感器数据主动上报（高频）— 开发文档

> 版本: 3.1
> 更新: 2026-08-03
> 适用固件: TTSatModule v1.3.0+
> 变更: 9.2 节补全倾角补偿方位角算法；硬铁校准由固件完成（per-device，存 NVS）

## 概述

设备支持 DA228EC 三轴加速度计 + MMC5603NJ 三轴磁传感器。本文档描述**高频主动上报**机制：APP 开启后，设备以 **50ms（20Hz）** 主动推送传感器原始数据；通话期间自动降速到 **500ms（2Hz）**，避免影响语音流。

> ⚠️ 本机制为 v3.0 新增，与旧版（`sensor_ble_cmd.md` v2.0 的 500ms 上报）**不兼容**：
> - 旧版：上报走 Control 特征值（0xABFD），14 字节带 0x74 前缀
> - 新版：上报走**独立 Sensor 特征值（0xABF2）**，13 字节无前缀，频率 50ms
>
> 建议新版 APP 使用本文档协议。单次查询命令（0x74）仍保留不变。

---

## 1. GATT 通道

| 项目 | UUID | 属性 | 用途 |
|------|------|------|------|
| System Service | `0xABFC` | — | 系统服务 |
| Control 特征值 | `0xABFD` | Read / Write / Notify | 下发命令、接收命令响应 |
| **Sensor 特征值（新增）** | **`0xABF2`** | **Read / Notify** | **传感器数据高频推送** |

- **命令下发**：Write 到 `0xABFD`
- **命令响应**：Notify from `0xABFD`
- **传感器数据流**：Notify from `0xABF2`（需先订阅 CCCD）

---

## 2. 命令定义

命令通过 Control 特征值（0xABFD）下发，复用既有命令码：

| 命令 | 码 | 方向 | 说明 |
|------|----|------|------|
| `GET_SENSOR_STATUS` | 0x74 | APP → 设备 → APP | 单次查询最新一帧（响应走 0xABFD，向后兼容） |
| `ENABLE_SENSOR_REPORT` | 0x75 | APP → 设备 → APP | 开启高频主动上报（推到 0xABF2） |
| `DISABLE_SENSOR_REPORT` | 0x76 | APP → 设备 → APP | 关闭主动上报 |

### 命令包格式（Write 到 0xABFD）

```
[seq][cmd][param_len][params...][crc16_lo][crc16_hi]
```
- `seq`：序号（APP 自定，响应用同序号匹配）
- `cmd`：命令码
- `param_len`：参数字节数
- `crc16`：CRC16-MODBUS 校验（整包除 crc 外）

### 响应包格式（Notify from 0xABFD）

```
[seq][cmd][resp_code][data_len][data...]
```
- `resp_code`：0x00 = OK

---

## 3. ENABLE_SENSOR_REPORT (0x75) — 开启上报

### 请求

| 字段 | 值 | 说明 |
|------|----|------|
| cmd | 0x75 | |
| param_len | 1 | |
| param[0] | 0 或 1 | 0 = 关闭，1 = 开启（省略时默认开启） |

### 响应

| 字段 | 说明 |
|------|------|
| resp_code | 0x00 = OK |
| data[0] | 当前状态：0 = 已关闭，1 = 已开启 |

### 交互示例

```
开启: seq=0x01, cmd=0x75, param_len=0x01, param=[0x01]  (+crc16)
响应: seq=0x01, cmd=0x75, resp_code=0x00, data_len=0x01, data=[0x01]
      → 设备开始向 0xABF2 以 50ms/包推送
```

> **会话续期**：每次收到 0x75(param=1) 都会重置 30s 会话计时器。APP 需周期性（建议每 **25s**）重发 0x75(param=1) 续期，否则 30s 后设备自动关闭上报（详见第 6 节）。

---

## 4. 主动上报 Notification 格式（0xABF2）

上报开启后，设备通过 **Sensor 特征值 0xABF2** 发送 Notify。

### Notification 负载（13 bytes，无前缀）

| 偏移 | 长度 | 类型 | 名称 | 说明 |
|------|------|------|------|------|
| 0 | 1 | uint8 | flags | 数据有效标志 |
| 1-2 | 2 | int16 LE | accel_x | X 轴加速度，单位 **mg** |
| 3-4 | 2 | int16 LE | accel_y | Y 轴加速度，单位 **mg** |
| 5-6 | 2 | int16 LE | accel_z | Z 轴加速度，单位 **mg** |
| 7-8 | 2 | int16 LE | mag_x | X 轴磁场，单位 **mG** |
| 9-10 | 2 | int16 LE | mag_y | Y 轴磁场，单位 **mG** |
| 11-12 | 2 | int16 LE | mag_z | Z 轴磁场，单位 **mG** |

> 注意：与旧版（14 字节带 0x74 前缀）不同，**新版无 report_id 前缀**，因为 0xABF2 是专用数据通道，整包就是 13 字节传感器数据。

### flags 位定义

| Bit | 名称 | 说明 |
|-----|------|------|
| 0 | ACCEL_VALID | 1 = 加速度计数据有效 |
| 1 | MAG_VALID | 1 = 磁传感器数据有效 |
| 7-2 | 保留 | 固定为 0 |

### 单位与量程

| 传感器 | 单位 | 量程 | 备注 |
|--------|------|------|------|
| 加速度计 | mg（毫g，1g=1000mg） | ±2000 mg（±2g） | 静止时 Z 轴约 ±1000mg |
| 磁传感器 | mG（毫高斯，1G=1000mG） | ±30000 mG | 地磁场约 300~500mG |

---

## 5. 推送速率（动态）

| 场景 | 速率 | 说明 |
|------|------|------|
| 上报开启（空闲） | **50ms / 包（20Hz）** | 默认高速 |
| 上报开启 + 通话中 | **500ms / 包（2Hz）** | 自动降速，避免影响语音数据流 |
| 上报关闭 | 0（任务休眠） | 零采样、省电 |

- 通话状态由设备判断（卫星通话进行中即降速），APP 无需干预。
- Notify 为**无响应（no-respond）**通知，设备不重传丢包——连续数据流，偶尔丢包无影响，下个 50ms 即新数据。

---

## 6. 会话超时（自动关闭）

为防止 APP 异常退出/忘记关闭导致持续耗电，上报采用**会话制**：

- 自最近一次 `ENABLE(0x75 param=1)` 起，**30 秒**内若未再收到续期命令，设备**自动关闭**上报（任务休眠）。
- APP 必须**周期性续期**：建议每 **25 秒**重发一次 `0x75 param=1`（收到响应 data[0]=1 即续期成功）。

```
APP: 0x75(1) ──► 设备开始推送 + 计时
     ↑ 每 25s 重发续期
     └─ 若 30s 未续期 ──► 设备自动关闭
```

---

## 7. 单次查询（可选，向后兼容）

不订阅/不开启上报时，也可单次取一帧：

- **方式 A**：Read 特征值 `0xABF2` → 返回最新 13 字节（格式同上表）。
- **方式 B**：发命令 `GET_SENSOR_STATUS(0x74)` 到 0xABFD → 响应 data 为 13 字节（格式同上表），走 0xABFD 响应。

## 8. 完整 APP 集成流程

```
1. 连接设备，发现 Service 0xABFC
2. 订阅 Sensor 特征值 0xABF2 的 CCCD（开启 Notify）
3. Write 0xABFD: ENABLE_SENSOR_REPORT(0x75, param=1)
   → 收到 0xABFD 响应 data[0]=1
4. 开始接收 0xABF2 Notify，每 50ms 一包 13 字节 → 解析传感器数据
5. 后台定时器：每 25s 重发 0x75(param=1) 续期
6. 通话中：设备自动降为 500ms/包，APP 无需处理
7. 停止：Write 0xABFD: DISABLE(0x76) 或 0x75(param=0)
   → 取消订阅 0xABF2 CCCD
```

### 断开处理

- **BLE 断开**：设备**自动关闭**上报（采样任务休眠）。APP 重连后需重新走第 2~3 步（订阅 + ENABLE）。
- 这与旧版不同（旧版断开不停止）。

## 9. APP 端解析示例

### 9.1 解析 13 字节 Notification

```c
// data[] 为收到的 13 字节 0xABF2 notify
uint8_t  flags  = data[0];
int16_t  ax = (int16_t)((data[2] << 8) | data[1]);   // mg
int16_t  ay = (int16_t)((data[4] << 8) | data[3]);
int16_t  az = (int16_t)((data[6] << 8) | data[5]);
int16_t  mx = (int16_t)((data[8]  << 8) | data[7]);  // mG
int16_t  my = (int16_t)((data[10] << 8) | data[9]);
int16_t  mz = (int16_t)((data[12] << 8) | data[11]);

if (!(flags & 0x01)) { /* 加速度无效 */ }
if (!(flags & 0x02)) { /* 磁场无效 */ }
```

### 9.2 角度计算（仰角 + 倾角补偿方位角）

> 重要：设备上报的 `mx/my/mz` **已由固件做了硬铁校准**（减去 per-device 偏移）。
> APP 拿到的是去偏移后的磁场。下面直接用即可，无需再减硬铁偏移。
> 软铁校准暂不做（实测不够准再加）。

#### 9.2.1 单位归一

```c
#define PI  3.14159265f

/* 加速度 mg → g（用于算姿态角） */
float ax_g = ax / 1000.0f;
float ay_g = ay / 1000.0f;
float az_g = az / 1000.0f;

/* 磁场保持 mG（比例运算，单位不影响角度） */
float mxf = (float)mx;
float myf = (float)my;
float mzf = (float)mz;
```

#### 9.2.2 由加速度算姿态（Pitch / Roll）

```c
/* Pitch（俯仰 / 仰角）：设备前端抬起的角度，0=水平，+=抬头 */
float pitch = atan2f(-ax_g, sqrtf(ay_g*ay_g + az_g*az_g));   /* 弧度 */

/* Roll（横滚）：设备侧倾角度，0=水平 */
float roll  = atan2f(ay_g, az_g);                            /* 弧度 */

float elevation = pitch * 180.0f / PI;   /* 仰角（°），即设备指向的俯仰 */
```

#### 9.2.3 倾角补偿方位角（核心）

设备倾斜时，必须先把磁向量从**设备坐标系**旋转到**水平面**，再算航向，否则方位角严重失真：

```c
float cp = cosf(pitch), sp = sinf(pitch);
float cr = cosf(roll),  sr = sinf(roll);

/* 把磁向量投影到水平面 */
float Xh = mxf * cp + mzf * sp;
float Yh = mxf * sr * sp + myf * cr - mzf * sr * cp;

/* 水平面内算航向 */
float heading = atan2f(Yh, Xh) * 180.0f / PI;   /* ° */
if (heading < 0) heading += 360.0f;             /* 0=北 90=东 180=南 270=西 */
```

> ⚠️ **轴序与符号需按实际安装方向校验**。上面是常见约定（X 朝设备前端、Y 朝左、Z 朝上）。
> 若实测方位角整体偏 180°/方向反转，调整 `atan2f` 的符号或 Xh/Yh 的正负：
> - 方向差 180° → `atan2f(-Yh, -Xh)` 或整体取反
> - 东西颠倒 → 交换 Xh/Yh 或改 Yh 符号
> - 建议先用"水平放置、分别朝北/东/南/西"验证四向，再微调符号。

#### 9.2.4 何时可退化为 2D（无倾角补偿）

仅当**确认设备始终保持水平**（如固定在水平支架上）时，可直接用简化公式：

```c
float heading = atan2f(myf, mxf) * 180.0f / PI;
if (heading < 0) heading += 360.0f;
```

手持或晃动场景**必须用 9.2.3 的倾角补偿版本**，否则倾斜几度方位角就会偏十几度。

#### 9.2.5 前置条件：硬铁校准

方位角准的前提是**设备已做过硬铁校准**（固件端按键触发，存 NVS）。未校准时偏移未去除，方位角会系统性偏移。APP 可提示用户先完成一次硬铁校准（长按设备按键 5s + 360° 旋转）。

## 10. 注意事项

1. **flags 判断**：每包先检查 flags，只处理有效字段（bit0=加速度，bit1=磁场）。
2. **默认关闭**：开机后上报状态为关闭，且采样任务休眠；必须 APP 发 0x75(param=1) 才开始。
3. **必须续期**：30s 无续期自动关闭，建议每 25s 重发 0x75(param=1)。
4. **BLE 断开自动关闭**：重连后需重新订阅 + ENABLE。
5. **丢包不重传**：Notify 为无响应通知，BLE 缓冲满时丢包，APP 不应依赖每包必达。
6. **通话降速**：通话中自动降为 500ms，属正常行为。
7. **坐标系**：加速度计与磁传感器坐标系一致，轴向参考硬件安装方向。
8. **磁传感器校准**：首次使用建议做 8 字校准获取硬铁偏移。
9. **Debug 连接**：0x74/0x75/0x76 命令允许 Debug 连接使用。
10. **特征值区分**：传感器数据流走 `0xABF2`（13B 无前缀），命令响应走 `0xABFD`——两者不要混淆。
