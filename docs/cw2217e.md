各寄存器详解
1. VERSION (0x00) — 版本寄存器
表格属性描述类型只读 (R)默认值0xA0格式8 位无符号整数
说明：用于确认芯片通信正常。无论在关断模式还是激活模式，固定值为 0xA0。

2. VCELL (0x02 ~ 0x03) — 电池电压寄存器
表格属性描述类型只读 (R)地址0x02 (高字节)，0x03 (低字节)默认值0x0000格式14 位无符号整数 (高 14 位有效)
说明：连续监测 VCELL 引脚与 VSS 引脚之间的电池电压。使用 14 位 Σ-Δ ADC 转换。
转换公式：
V (µV) = Value(0x02, 0x03 DEC) × 312.5
位图：
  0x02 (High Byte)        0x03 (Low Byte)
  MSB                     LSB   MSB                   LSB
  7   6   5   4   3   2   1   0   7   6   5   4   3   2   1   0
+-------------------------------+-------------------------------+
| D13 D12 D11 D10 D9  D8  D7  D6 | D5  D4  D3  D2  D1  D0  X   X |
+-------------------------------+-------------------------------+
  ↑--- 14 位数据 (VCELL[13:0]) --↑
电气特性：
表格参数典型值测量范围2.5V ~ 5.0V分辨率312.5 µV有效位数14 bits转换时间5 ms误差 (25°C, 4V)±7.5 mV

3. SOC (0x04 ~ 0x05) — 荷电状态寄存器
表格属性描述类型读写 (R/W)地址0x04 (高字节/整数部分)，0x05 (低字节/小数部分)默认值0x0000格式16 位无符号整数
说明：报告电池的荷电状态 (SOC)。
转换公式：
SOC (%) = Value(0x04 DEC) + Value(0x05 DEC) / 256
表格字节描述示例0x04整数部分65 → 65%0x05小数部分，LSB = 1/256%128 → 0.5%
示例：若 0x04 = 0x41 (65)，0x05 = 0x80 (128)，则 SOC = 65 + 128/256 = 65.5%。

4. TEMP (0x06) — 温度寄存器
表格属性描述类型读写 (R/W)默认值0x00格式8 位无符号整数
说明：报告电池 NTC 热敏电阻测量的温度。
转换公式：
TEMP (°C) = -40 + Value(0x06 DEC) / 2
表格寄存器值温度 (°C)0x00 (0)-40.00x50 (80)0.00x5A (90)5.00x64 (100)10.00xC8 (200)60.0

5. CONFIG (0x08) — 配置寄存器
表格属性描述类型读写 (R/W)默认值0xF0
说明：用于控制芯片的电源状态和复位。
操作说明（数据手册原文）：
表格操作写入值说明清除 SLEEP 位0x30退出关断模式，进入休眠状态的第一步清除 RESTART 位0x00触发重启，进入激活模式（第二步）完整上电流程先写 0x30，再写 0x00从关断模式进入激活模式
代码示例：
cvoid CW2217E_Activate(void) {
    I2C_WriteByte(0xC8, 0x08, 0x30);   // 第一步：清除 SLEEP
    delay_ms(10);
    I2C_WriteByte(0xC8, 0x08, 0x00);   // 第二步：清除 RESTART，进入激活
    delay_ms(100);
}

7. SOC_ALERT (0x0B) — SOC 警报寄存器
表格属性描述类型读写 (R/W)默认值0x14 (20%)
说明：设置 SOC 中断的触发阈值。

举例：默认值 0x14 = 20，表示当 SOC 每变化 20% 时产生一次中断。

8. TEMP_MAX (0x0C) — 最高温度阈值寄存器
表格属性描述类型读写 (R/W)默认值0xAA (45°C)格式8 位无符号整数，LSB = 0.5°C
说明：当温度达到此值时，置位 TMX_INT，并在 INT_N 引脚产生低脉冲。
转换公式：
TEMP_MAX (°C) = -40 + Value(0x0C DEC) / 2
示例：0xAA = 170，则 TEMP_MAX = -40 + 170/2 = 45°C

9. TEMP_MIN (0x0D) — 最低温度阈值寄存器
表格属性描述类型读写 (R/W)默认值0x50 (0°C)格式8 位无符号整数，LSB = 0.5°C 
说明：当温度低于此值时，置位 TMN_INT，并在 INT_N 引脚产生低脉冲。
转换公式：
TEMP_MIN (°C) = -40 + Value(0x0D DEC) / 2
示例：0x50 = 80，则 TEMP_MIN = -40 + 80/2 = 0°C

10. CURRENT (0x0E ~ 0x0F) — 电流寄存器
表格属性描述类型只读 (R)地址0x0E (高字节)，0x0F (低字节)默认值0x0000格式16 位有符号整数 (2's 补码)
说明：报告流过感测电阻 (典型 10mΩ) 的电流。正值表示充电，负值表示放电。
转换公式：
I (A) = (52.4 × Value(0x0E, 0x0F DEC)) / (32768 × Rsense(mΩ))
感测电阻与分辨率对照表：

典型值说明：
表格寄存器值含义0x00000mA (无电流)0x7FFF最大充电电流0x8001最大放电电流

11. T_HOST (0xA0 ~ 0xA1) — 主机上报温度寄存器
表格属性描述类型读写 (R/W)地址0xA0 (高字节)，0xA1 (低字节)默认值0x0000格式16 位有符号整数
说明：当电池配置文件配置为主机报告温度模式时，MCU 通过此寄存器写入温度值。算法约每 4 秒 检查一次，且 低字节 (0xA1) 必须与上次写入的值不同 才会更新。
转换公式：
T_HOST (°C) = -40 + Value(0xA0 DEC) / 2 + Value(0xA1 DEC) / 512

+-------------------------------+-------------------------------+

12. USER_CONF (0xA2) — 用户配置寄存器
表格属性描述类型读写 (R/W)默认值0x00格式8 位自由配置寄存器 
说明：开发者可自由读写此寄存器，用于存储自定义标志或配置。芯片内部不对此寄存器做任何处理。

13. CYCLECNT (0xA4 ~ 0xA5) — 循环次数寄存器
表格属性描述类型读写 (R/W)地址0xA4 (高字节)，0xA5 (低字节)默认值0x0000格式16 位无符号整数
说明：记录电池的充放电循环次数。
转换公式：
Cycle Count = Value(0xA4, 0xA5 DEC) / 16
示例：若 0xA4=0x01, 0xA5=0x00，则 CYCLECNT = 256，循环次数 = 256/16 = 16 次

14. SOH (0xA6) — 电池健康状态寄存器
表格属性描述类型读写 (R/W)默认值0x64 (100%)格式8 位无符号整数，1% / LSB范围0x00 (0%) ~ 0x64 (100%)
说明：估算电池的健康状态，100% 表示全新电池。随着使用和老化，该值会逐渐降低。

15. AVE_CUR (0xA8 ~ 0xA9) — 平均电流寄存器 *
表格属性描述类型只读 (R)地址0xA8 (高字节)，0xA9 (低字节)默认值0x0000格式16 位有符号整数 (2's 补码)
说明：报告平均电流转换结果，公式与 CURRENT 寄存器相同。

注意：此寄存器由未来固件版本支持。如需要请联系销售部门。

说明：报告芯片内运行的固件版本。
